During my internship at **Amazon Web Services Vietnam Co., Ltd.** from **April 20, 2026** to **July 12, 2026**, I had the opportunity to learn, practice, and apply the knowledge I acquired at university in a professional working environment. This internship also marked my first experience working extensively with **cloud computing technologies**, allowing me to gain a deeper understanding of modern cloud-based application development.

In the project, I was responsible for the **Notification, Analytics, Deployment, and Monitoring** modules.

For the **Notification** module, I researched and implemented AWS Lambda functions responsible for sending confirmation emails after users successfully registered for an event and reminder emails before the event date. This helped me understand event-driven architecture, asynchronous processing, and the integration between AWS services to automate notification workflows.

For the **Analytics** module, I developed APIs that provide statistical data for administrators. These APIs aggregate information from multiple DynamoDB tables, including **Event**, **Registration**, and **Attendance**, to calculate important metrics such as the total number of events, total registrations, confirmed tickets, waiting list participants, and attendance rates. I also learned how to present these statistics on an administrative dashboard, enabling users to monitor event performance effectively.

Regarding **Deployment and Monitoring**, I explored the process of deploying the frontend application to **Amazon S3** and distributing static content through **Amazon CloudFront**. In addition, I learned how to use **Amazon CloudWatch** to collect logs from AWS Lambda functions, monitor application execution, identify runtime errors, and support debugging throughout the development lifecycle. These tasks provided valuable experience in deploying and operating cloud-native applications.

Alongside the project, I completed a variety of AWS hands-on laboratories covering services such as **AWS Identity and Access Management (IAM)**, **Amazon EC2**, **Amazon VPC**, **Resource Groups**, **Resource Tags**, **IAM Permission Boundaries**, **AWS Key Management Service (KMS)**, and other topics related to cloud security, resource management, and infrastructure deployment. These practical exercises significantly strengthened my understanding of how AWS services interact within a real-world cloud architecture.

Beyond the assigned technical tasks, I actively studied the official AWS documentation and other technical resources to broaden my knowledge. This not only improved my programming skills but also enhanced my ability to read and understand technical documentation written in English.

After completing the internship, I believe that I have made considerable progress in both technical knowledge and professional working skills. I became more confident in learning new technologies, solving technical problems independently, and adapting to a collaborative development environment. However, I also recognize that I still need to improve my ability to design large-scale cloud architectures, optimize system performance, and strengthen my communication skills when working within a team.
