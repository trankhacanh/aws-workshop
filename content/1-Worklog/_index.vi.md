Trong suốt quá trình thực tập, tôi đã tìm hiểu và thực hành nhiều dịch vụ của AWS, từ hạ tầng cơ bản, mạng, bảo mật, lưu trữ đến phát triển ứng dụng Serverless. Bên cạnh việc hoàn thành các bài lab của AWS Study Group, tôi còn trực tiếp tham gia phát triển hệ thống **Event Management** trên nền tảng AWS với kiến trúc Serverless, sử dụng các dịch vụ như **AWS Lambda**, **Amazon API Gateway**, **Amazon DynamoDB**, **Amazon Cognito**, **Amazon EventBridge**, **Amazon S3**, **Amazon CloudFront**, **Amazon SES**, **AWS SAM**, **Amazon CloudWatch** và nhiều dịch vụ khác. Quá trình thực tập giúp tôi nâng cao kiến thức chuyên môn, kỹ năng triển khai hệ thống Cloud và kinh nghiệm làm việc trong một dự án thực tế.

**Tuần 4:** [Tìm hiểu các dịch vụ Compute và Storage trên AWS như Amazon EC2, Amazon S3, AWS Backup, File Storage Gateway và Amazon CloudFront](1.4-week4/)

**Tuần 6:** [Thực hành quản lý tài nguyên bằng Tags, IAM, AWS KMS và triển khai Amazon EC2 Auto Scaling kết hợp Application Load Balancer](1.6-week6/)
