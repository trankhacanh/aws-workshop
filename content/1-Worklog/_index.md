Throughout the internship, I studied and applied a wide range of AWS Cloud services, from core infrastructure and networking to serverless application development and deployment. The work included hands-on experience with **Amazon EC2**, **Amazon VPC**, **Amazon S3**, **Amazon CloudFront**, **Amazon DynamoDB**, **Amazon Cognito**, **Amazon EventBridge**, **AWS Lambda**, **AWS SAM**, **Amazon SES**, **AWS IAM**, **AWS CloudWatch**, **AWS KMS**, **AWS Security Hub**, and many other AWS services. I also participated in designing, developing, deploying, and optimizing a cloud-native event management system built on a Serverless architecture, while continuously improving my practical knowledge through AWS labs, company projects, and technical sharing sessions.

**Week 1:** [Registered an AWS account and completed five introductory AWS labs to earn 100 AWS Credits](1.1-week1/)

**Week 2:** [Joined the First Cloud AI Journey (FCAJ), completed Module 01, and practiced AWS Budgets and Support Plans](1.2-week2/)

**Week 3:** [Studied AWS networking fundamentals and completed hands-on labs on Amazon VPC, Site-to-Site VPN, Route 53 Resolver, VPC Peering, and AWS Transit Gateway](1.3-week3/)

**Week 4:** [Learned AWS Compute and Storage services, including Amazon EC2, Amazon S3, AWS Backup, File Storage Gateway, and Amazon CloudFront](1.4-week4/)

**Week 5:** [Completed AWS security and migration labs, including VM Import/Export, Amazon FSx, AWS IAM, AWS KMS, AWS Security Hub, and AWS Lambda automation](1.5-week5/)

**Week 6:** [Practiced AWS resource governance, IAM access control, AWS KMS encryption, and Amazon EC2 Auto Scaling with Application Load Balancer](1.6-week6/)

**Week 7:** [Studied the Serverless project architecture and core AWS services, including AWS Lambda, AWS SAM, Amazon API Gateway, Amazon Cognito, Amazon DynamoDB, and Amazon SES](1.7-week7/)

**Week 8:** [Developed the NotificationLambda module, integrated Amazon EventBridge, Amazon SES, and Amazon DynamoDB, and deployed the notification workflow on AWS](1.8-week8/)

**Week 9:** [Developed the Analytics module and React dashboard, integrated Amazon DynamoDB and Amazon S3 analytics APIs, and completed end-to-end testing](1.9-week9/)

**Week 10:** [Migrated the system to an Event-Driven Architecture using Amazon EventBridge, deployed the backend on AWS, and prepared the project documentation](1.10-week10/)

**Week 11:** [Deployed the frontend using Amazon S3 and Amazon CloudFront, configured Amazon Cognito and Amazon CloudWatch, and completed the final system integration and testing](1.11-week11/)

**Week 12:** [Enhanced the Event Management System, researched an AI-powered AWS e-commerce platform, and participated in on-site technical activities and knowledge-sharing sessions](1.12-week12/)
