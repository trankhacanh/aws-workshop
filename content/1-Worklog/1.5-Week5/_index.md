### Week 5 Objectives

* Complete all hands-on labs in **Module 04**.
* Understand the process of migrating virtual machines from an on-premises environment to AWS using VM Import/Export.
* Learn how to deploy and manage Amazon FSx for Windows File Server.
* Study AWS security services, including IAM, AWS Organizations, AWS IAM Identity Center (SSO), AWS Key Management Service (KMS), and AWS Security Hub.
* Understand common security standards such as CIS Benchmark and PCI DSS, and learn how AWS Security Hub can be used to evaluate compliance.
* Practice using AWS Lambda to automate resource management and optimize Amazon EC2 operating costs.
